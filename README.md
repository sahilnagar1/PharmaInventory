PharmaInventory - Pharmaceutical Expiry & Batch Tracking SystemA full-stack .NET 10 ASP.NET Core MVC web application designed for real-time pharmaceutical inventory management, batch tracking, and expiry risk monitoring. The system automatically highlights inventory risk levels using conditional visual alerts and enforces cross-field data integrity rules to ensure regulatory compliance.   
🚀 Key FeaturesReal-time Expiry Status Tracking: Dynamically evaluates batch expiry dates against current dates to display status badges:🔴 Expired: Expiry date is in the past.   🟡 Expiring Soon: Expiry date is within 60 days.   🟢 Safe: Expiry date is beyond 60 days.   Automated Risk Sorting: Table records automatically sort by urgency (earliest expiry first) to reduce operator cognitive load and surface high-risk stock immediately.   Cross-Field Data Integrity: Custom model validation (IValidatableObject) blocks illegal submissions, such as an expiry date preceding a manufacture date or negative stock counts.   Batch Search Filtering: Enables quick querying of specific batches via LINQ filters.   Dynamic Database Seeder: Seeds 20 sample items with relative dates (DateTime.Now) on initial launch to ensure active color formatting during testing or demos.   🛠️ Tech Stack & ArchitectureFramework: .NET 8.0 ASP.NET Core MVC   Language: C#   Database & ORM: Entity Framework Core with SQL Server (LocalDB)   Frontend: Razor Pages, Bootstrap 5, HTML5/CSS3   Architecture Pattern: Model-View-Controller (MVC)   Model: Handles data schema, dynamic status logic, and validation rules.   View: Displays responsive dashboards and conditional color-coded tables.   Controller: Manages request execution, search filtering, and database operations.
